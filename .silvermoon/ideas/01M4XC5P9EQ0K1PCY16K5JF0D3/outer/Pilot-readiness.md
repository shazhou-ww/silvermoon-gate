## 凭据交付与调用方约束

- bootstrap 经批准的密管或加密一次性交付，不在聊天、邮件正文、剪贴板、控制台、仓库或审阅证据中传递明文。按既有示例安全注入调用方受限运行时文件时，须有加密存储和仅当前运行身份可读的权限（Unix
  0600 / Windows
  ACL）；只保留非敏感交付回执与公共 credentialId，不保存秘密副本。
- Gate 仅存域分隔 hash；bootstrap 最长 30 天，token
  300 秒、无 refresh。token 只在运行内存使用；HTTP、日志、截图、trace 和审计证据不得包含秘密、hash、Authorization、Cookie 或原始 token 交换响应。
- 调用方在首次调用前持久保存同一 idempotency
  key、不可变输入及自己计算的预期 Gate
  payloadDigest。结果不明只能显式用相同 key/输入重查或重放，不能暗中刷新、重试、换 key 或从 Gate 响应抄取预期摘要。
- 仅 online
  approved 且预期摘要、schema、模板、请求归属及决定证据匹配才恢复调用方自己的无敏感测试步骤；pending、拒绝、撤回、断网、超时或认证失效都保持阻塞。Gate 不执行发布，不承诺 exactly-once 业务执行；试点不触及生产业务。
