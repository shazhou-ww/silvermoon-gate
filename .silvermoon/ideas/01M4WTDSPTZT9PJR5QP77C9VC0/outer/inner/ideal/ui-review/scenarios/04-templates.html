版本差异示例

v2 → v3：认证要求提高。已创建的请求仍使用原版本。

修改 schema / 认证要求必须发布新版本，不能保存覆盖 v3。

当前合格权限主体

release-owner · id-owner-demo

名单可以改变，但增删必须留审计。

移除 release-owner？

立即影响 v3 的待处理请求；过去决定保持不变。不在此处真的移除。

发布新版本

编辑 → schema 校验 → 载荷预览 → 发布确认；错误与并发冲突保留草稿。此示意不提供假发布按钮。

停用模板

只阻止新请求

现有 pending 请求继续按固定版本处理；此操作不撤回所有请求。
